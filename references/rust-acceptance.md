## 可重复执行

```bash
./scripts/verify-rust.sh
./scripts/build.sh
cargo run --locked --example create_fixture -- /tmp/chu-native-new-qa
./build/bin/chu --root /tmp/chu-native-new-qa/chu --home /tmp/chu-native-new-qa/home
```

生成器拒绝覆盖已有目录；每次验收使用新目录。所有生成数据、截图和打包产物保留在临时或忽略目录，不混入源码。
