## 数据与资源
- MCP/Agent 创建→启用→编辑→重命名→删除；稳定 ID 与 Agent 路径不变。
- MCP 四宿主原生/legacy 格式、同配置路径哈希更新、无关字段和旧备份保留。
- 任一目标被修改、冲突或不兼容时整项零写入；state 提交失败恢复所有目标与备份。
- 已有秘密不回填、默认保持；替换/移除有明确操作。快照、编辑 DTO、错误和截图不得泄密。
- 中央 Agent 文件被外部修改时拒绝更新与删除。

## 编辑和来源
- 原文读取失败不能保存空替代内容；重试成功后恢复编辑。
- Escape/关闭脏草稿确认，继续编辑保留内容，放弃后清空秘密模型。
- 预览后修改仓库即失效；安装固定预览 commit，分支前移不能改变安装内容。
- 未预览/无选择/同名候选冲突不能提交；旧 JSON 自动化接口继续兼容。

## 任务与导航
- 下载/扫描/预览可安全取消、120 秒网络阶段上限；取消后无后台资源写入。
- Commit/回滚不可取消或关窗，仍可浏览其他只读页。
- 页面往返恢复搜索/选择/滚动，方向键更新预览不写配置。
- 迟到任务回复不抢导航、不填错或关闭新的弹窗。

## 导入与阅读
- 搜索/宿主筛选不丢隐藏项勾选，重扫保留同指纹选择，变化项取消并解释。
- 同名或标识冲突即时禁提交；兼容目标移除明确提示，不自动恢复勾选。
- 总览资源数可跳转，待处理问题定位资源，宿主配置定位设置卡片。
- Markdown 预览/源码切换，代码与源码复制；标题/列表/引用/代码/表格/链接/CJK/CRLF。
- HTML 不执行、不采用外部颜色，图片不自动加载，复杂语法可回退完整原文。
